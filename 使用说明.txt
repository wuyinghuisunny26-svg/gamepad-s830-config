手柄控制 · 使用说明
================================================

【这是什么】
  明品 S830 Pro 手柄的电脑端配置工具。可以改按键映射、设连击，走蓝牙直连，
  不需要装任何软件、不需要 root、不需要官方 App。


【怎么用】
  1. 双击「启动.bat」
  2. 浏览器会打开 http://127.0.0.1:8765/
  3. 点右上角「连接手柄」，在弹窗里选 mingpin-S830Pro
  4. 点左边的按键 → 右边选目标按键 / 设连击 → 「保存到设备」

  必须用 Edge 或 Chrome。Firefox 不支持 Web Bluetooth。


【重要：连接前先删掉 Windows 的蓝牙配对】
  如果 Windows 设置里已经配对过这个手柄，它会自动连成"游戏手柄"，
  此时任何工具都连不上（蓝牙同一时间只允许一个设备连它）。

  正确做法：
    设置 → 蓝牙和其他设备 → 找到 mingpin-S830Pro → 删除设备
  然后用手柄按键唤醒它，再点工具里的「连接手柄」。


【关于按键映射】
  - 每次连接都会载入默认映射（主键映射到自己，M1~M4 留空）
  - 「保存到设备」会一次写入全部 20 个按键
  - 这个手柄只支持「按键 → 按键」，不支持映射到键盘

  为什么每次都从默认开始？
    这个设备不提供"读回当前映射"的指令（已实测确认），
    所以工具无法知道手柄里现在是什么配置，就统一从默认开始，
    你在默认基础上改成想要的即可。


【连击】
  选中按键后可以在右侧设置：
    模式：关闭 / 连击 / 自动连击
    频率：1 ~ 7（与官方 App 一致）
  开了连击的按键，在按键格左上角会有个「连」字标记。


【预设导入导出】
  右栏「导出预设」会存一个 JSON 文件，可以拷到别的电脑再「导入预设」。


【按键测试页】
  顶栏「按键测试」可以看手柄按键的实时状态，
  用来确认某个键实际触发的是什么。


【换到别的电脑】
  把整个文件夹拷过去，双击「启动.bat」就行。
  只需要 Windows 自带的 PowerShell，不用装 Python 或 Node。


【常见问题】
  Q: 弹窗里找不到手柄？
  A: 手柄休眠了。按一下手柄上的键唤醒它，再点连接。
     或者它已经被 Windows/手机连着，先断开。

  Q: 页面打不开 / 提示连接被拒绝？
  A: 启动.bat 的 PowerShell 窗口被关了。重新双击启动.bat。

  Q: 改完没反应？
  A: 确认点的是「保存到设备」而不是「应用到草稿」。
     日志里应该能看到两行 TX（一行 0x37 映射，一行 0x38 连击）。
