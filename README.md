# 手柄控制 · 明品 S830 Pro 按键重映射

一个纯网页版的游戏手柄配置工具。**打开网址就能用**，不用装软件、不用 root、不用官方 App。

> 适用于 **mingpin-S830Pro**（VID 0x0F / PID 0x1A，固件 3.09，mapVersion 4）

## 功能

- **按键映射**：20 个物理按键，可为每个键指定它要触发的目标按键
- **连击**：关闭 / 连击 / 自动连击，频率 1–7
- **设备信息**：型号、固件版本、VID/PID、协议版本
- **预设导入导出**：配置存成 JSON，可跨设备迁移
- **按键测试**：实时查看手柄按键状态

## 使用

1. 用 **Edge 或 Chrome** 打开本页（Firefox 不支持 Web Bluetooth）
2. 点「连接手柄」，在弹窗里选择 `mingpin-S830Pro`
3. 点左侧按键 → 右侧选目标按键 / 设连击 → 「保存到设备」

### ⚠️ 连接前必须先做的

**删掉 Windows 里这个手柄的蓝牙配对**（设置 → 蓝牙和其他设备 → 删除设备）。

原因：Windows 一旦配对，手柄开机就会自动连成"游戏手柄"，而蓝牙同一时间只允许一个中心设备连接——此时网页工具连不上。

手机同理，用工具前先断开手机蓝牙。

## 已知边界

| 项 | 状态 |
|---|---|
| 映射到键盘/鼠标 | ❌ 设备不支持，只能按键→按键 |
| 读回设备当前配置 | ❌ 设备无此指令（已实测确认）|
| 每次连接从默认开始 | ✅ 因此设计成默认基线，改完一次写入全部 20 键 |
| M1–M4 背键 | 只能作源，不能作目标；默认为空 |

## 协议说明

逆向自官方 App（Gamepad Space）并真机验证：

```
服务 95990001-1111-6666-8888-0123456789ab
  写入 95990002  通知 95990003

设备信息  10 03 03   →  VID/PID/型号/固件
能力包    10 03 02   →  deviceType/mapVersion
按键映射  10 31 37 <23字节>   [orgId] = 目标 id
连击配置  10 31 38 <46字节>   [orgId*2]=模式 [orgId*2+1]=频率
```

orgId：`0~15` 为主按键（与目标 id 同序），`16~17` 保留，`18~21` 为 M1~M4。

## 本地运行

若不想用 Pages，也可本地跑：

```
python -m http.server 8765
# 然后访问 http://127.0.0.1:8765/
```

Web Bluetooth 要求安全上下文，`file://` 直接打开无效，必须是 `https` 或 `localhost`。
